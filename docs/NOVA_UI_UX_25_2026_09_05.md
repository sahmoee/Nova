Implemented September 5, 2026. This is the UI half of the requested 50 Nova improvements. Every numbered item below is implemented in active iOS/iPadOS/tvOS source, not a proposal. No navigation-header, root-tab-bar, artwork, provider contract, persisted schema, or production service was replaced.

## Ownership and compatibility

Owner: Nova client UI. Producers: existing catalogue, subtitle, and download APIs. Consumers: shared iOS/iPadOS/tvOS views. No provider API or durable-data migration is required. Existing settings, library, watch history, offline files, and stream source contracts are preserved. Rollout is an ordinary client update after device QA; rollback is the prior client build without data repair. No new backend or public-site dependency is introduced.
