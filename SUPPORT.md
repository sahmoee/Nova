# Nova Support

For help with Nova, email [support@sowensstudios.com](mailto:support@sowensstudios.com). Include the Nova version, device model, iOS/tvOS version, and a short description of what happened. Do not send passwords, API keys, access tokens, private media URLs, or backup files containing credentials.

## Quick checks

1. Open **Settings → Sources & Add-ons → Health** to check configured services.
2. Confirm the device is online and can reach the source directly.
3. Reconnect an expired service under **Settings → Accounts**.
4. For playback issues, try the other playback engine or another file you are authorized to access.
5. Export the secret-free **Debug Report** from Settings and attach it to your support email.

Nova does not provide media, service subscriptions, or credentials. Questions about an external provider's availability, billing, or account should go to that provider.
