-------------------------------------
1. In your existing checkout, delete the old tracked files but keep the
   .git folder (do NOT delete .git).
2. Copy the CONTENTS of this Astra folder into that same directory.
3. Run: git add -A
   Git will detect most Swift files as renames since the bodies are
   nearly identical. Commit as usual.
Your BuildBuddy commit.sh / bump_version.sh still work unchanged and
still do the single authoritative version bump - I did not touch
MARKETING_VERSION or CURRENT_PROJECT_VERSION and did not pre-bump.

1. BUNDLE IDs changed:
      com.frametv.app.ios         ->  com.astra.app.ios

      com.frametv.app.ios.widgets ->  com.astra.app.ios.widgets
   Register these three App IDs in the Apple Developer portal and create

   carry over.

4. ON-DEVICE DATA: library, favorites, and app-group UserDefaults are
   keyed to the old App Group / bundle ID. A fresh install under the new
   identity starts empty. (You are pre-submission, so this is expected.)

5. GITHUB: rename the repo sahmoee/FrameTV to Astra on GitHub, then point
   your local remote at the new URL. I excluded the .git folder, so your
   existing remote still targets the old name until you change it.

6. CLOUDFLARE WORKER: wrangler.toml name is now astra-ai-worker. Run
   wrangler deploy to create it (this gives a NEW workers.dev URL), then
   paste that URL into the app's AI settings. The old worker keeps

   optional shared-token secret was renamed FRAMETV_SHARED_TOKEN ->
   ASTRA_SHARED_TOKEN; re-set it under the new name if you had used it.
