REMOVE CHOMP BARCODE LOOKUP AND REVERT TO PRIOR WATERFALL

SUMMARY

Removes the Chomp integration entirely and restores the barcode lookup to the
original source order. The Chomp branch was freezing the scanner on Looking up
product because it returned before clearing the loading state.

CHANGES

BarcodeScannerView.swift
  The Chomp branch is removed. resolveBarcode now runs the original waterfall:
  local cache, then OpenFoodFacts, then UPC Item DB, then the Worker AI fallback,
  then manual entry. This file is now identical to the prior committed version.

ChompFoodClient.swift
  Deleted via git rm in commit.sh, since the rsync overlay does not remove files.

NOTES

NutritionAPIConfig and APIResponseCache are kept; they are still used by the
LogMeal client and the Suggestic source. If you also want the Chomp key removed,
delete CHOMP_API_KEY from Secrets.xcconfig and the ChompAPIKey row from Info.plist
by hand from the current export. No secrets are included here.
